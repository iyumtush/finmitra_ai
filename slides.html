System Workflow Design

1. User Inputs

  • Financial Data: Income, Expenses, & Budgets
  • Media: Uploaded Payment Receipts & Bills
  • Queries: Natural Language Chat Questions
➔

2. AI Processing

  • Supabase: Secure storage & Auth
  • Context Engine: Aggregates live user data
  • Gemini Vision: OCR on receipts to extract JSON
➔

3. System Outputs

  • Dashboard: Visual charts & live summaries
  • Automation: Auto-logged transactions
  • Advice: Personalized financial & budget guidance

Features Developed Till Now

Secure Authentication & Dashboard

Supabase-backed login with a real-time summary dashboard for Income, Expenses, and Savings.

Transaction Management

Full CRUD operations for managing daily expenses and income streams with smart categorization.

Goal-Oriented Budgeting

Set, track, and monitor category-specific monthly budgets with visual progress indicators.

Context-Aware AI Chatbot

Gemini-powered financial assistant that answers questions based on the user's actual live database records.

Multimodal Receipt Parsing

Upload receipt images to the AI which automatically extracts the amount, category, and date into a new transaction.

Persistent Chat History

Locally stored chat sessions with a dedicated history view to look back at past AI financial advice.
